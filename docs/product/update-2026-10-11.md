## 本轮保留了什么

| 内容 | 当前实现 | 还缺什么 |
|---|---|---|
| 提问先过 LLM（REQ-015） | 可开关的一次 JSON 规划；原问题保留，关键词进 FTS，子问题/语义句进 Qdrant；最多 5 路、合并总 Top-5，全部沿用权限与版本过滤；失败回退原问题 | 真实 GLM 格式成功率、开关前后召回/答案质量/耗时/费用对比；不能宣称已提高召回 |
| 合规模型审计回答（REQ-008） | admin/compliance 受控入口；合法条件查询、当前权限脱敏、哈希链验证后，最多 20 个可见事件供模型解释并引用 `[E序号]`；失败回退条件查询结果 | 真实模型报告质量、用户/过去 30 天筛选准确性和合规角色完整人工验收 |
| 零证据与撤权 Demo（REQ-002/005） | 没有可用证据时由服务端直接返回统一提示，不调用回答模型；未知问题与撤权后无结果不暗示受限资料存在；保留账号/绑定有效的全部读取撤权回归 | 固定正负对照、前后请求与旧原文访问的真人验收和录制 |
| Prompt 与诊断（REQ-019/018） | 原问题、独立系统指令、授权证据分区；自然分段、相关内容、就近引用；记录版本、实际型号、调用数、用量和安全失败状态 | 固定题目下真实回答质量、长段/抄写改善及费用测量 |
| 模型复核（REQ-009 团队扩展） | **已取消**：删除业务/审计的第二次模型判断、反馈重答、专用配置/UI/评测；旧 `LLM_REVIEW_*` 无法重新开启 | 不再列为交付待办；确定性格式、编号、权限、版本检查仍保留，不承诺逐句事实正确 |

上一版已经有：Part A 解析与 SQLite 事实库、Qdrant/FTS 授权检索、独立管理员与六个演示员工、持久化系统内撤权、原文/交付检查、哈希链审计。没有在这轮重新建设这些能力。当前存储为 SQLite 事务审计链，JSON 是可导出的表示，不是每次请求生成一个独立 JSON 文件。

## 五个场景：最高优先级

| 场景 | 当前边界 | 下一步验收 |
|---|---|---|
| 跨来源问答与引用 | 链路可以跑；编号合法不等于逐句支持 | 固定问题、身份、正确证据与答案要点；人工核对跨来源关系及引用，记录真实 provider |
| 数据新鲜度 | 只有离线快照一致性和已知版本门闩；不等于来源更新被自动发现 | 最小受控来源更新→采集→版本保存→两类索引发布→同题返回新版本，测实际时间；保留旧版本但当前检索只读生效版本，覆盖回退 |
| 无权限不泄漏 | 索引内过滤、证据二次检查、零证据提示已有回归 | 同题有权/无权对照；检查正文、标题、链接、数量、建议词和模型输入，不用“非技术部门”代替真实 ACL |
| 实时撤权 | 系统内持久化撤权已实现；原平台撤权同步仍 `not_enabled` | 账号仍有效时撤销全部读取权限，验证同题零证据、旧原文不可读、期间/交付撤权、另一员工正常；明确仅证明系统内撤权 |
| 合规人员审计查询 | 条件查询、脱敏与模型解释代码已有 | 搜索/回答后按用户、时间、请求 ID 查记录；验证 E 引用、普通员工拒绝、业务明文脱敏、查询自身入链和副本篡改检测 |

五个案例都要保存预期、实际结果、步骤、运行版本和未验证边界。现有 Part A 离线评测与故障注入测试不能替代真实集成回答评测；模型辅助生成报告可行，但结论、指标和图表只能来自实际运行。

## 会议内容的落实顺序

1. **先补交付缺口**：新鲜度/有效版本最小闭环；并行做五场景固定评测、合规报告验收和正负案例录制。先保证能完整演示，再优化视频剪辑。
2. **评测驱动的检索和权限改进**：测试规划开关，修真实格式问题；明确 EnterpriseRAG/OrgForge 的 ACL 来源与推断边界，优先用可靠字段/规则匹配，歧义才用模型。模型评分不能凭空授予权限；未知权限不自动公开。项目/部门不是权限的替代。
3. **未来 Codex 工具/插件（REQ-020）**：目标是复用统一服务，前端保留作验收演示。先确定协议和可信最终用户身份，保证上游不能在参数中随意指定角色或用户；本轮未实现插件，也不恢复 Auth0 页面。
4. **后续数据工程（REQ-014/015/004）**：四平台独立 Connector、Slack 线程聚合/噪声筛选、可解释分层、项目/部门分类路由、完整增量/删除/历史/回滚；权限不同的内容不能汇总成更宽权限的摘要。
5. **规模与展示（REQ-018/013）**：真实延迟、费用、吞吐与日志增长；获奖案例和 EnterpriseRAG 产品演示调研；Fancy Demo、架构图、启动说明、真实 CodeBuddy/WorkBuddy 开发证明与提交表核对。

原平台权限同步维持既有阶段性延期；不能在演示中宣称实现。跨来源权威冲突（REQ-011）及生产审计保留/外部锚定为后续专题。模型复核已取消，不重新排入待办。
