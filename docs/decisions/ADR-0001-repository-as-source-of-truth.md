# ADR-0001：以 Git 仓库作为项目唯一事实源

- 状态：Accepted
- 日期：2026-09-29
- 决策人：ContextLedger 团队

## 背景

项目需要同时维护需求、代码、测试、演示和安全说明。若 Obsidian、聊天记录和项目文件夹各保留一份状态，同一要求很容易只更新其中一部分，协作者也无法在一次评审中确认变更是否完整。

## 决策

项目文件夹及其 Git 历史是唯一事实源。需求使用稳定的 `REQ-xxx` 标识，并在机器可读台账中关联代码、测试和文档。重要架构决定使用 ADR。所有交付性变化通过分支和 Pull Request 合并。

远程协作仓库固定为 `https://github.com/Panyuxiang0830/Hackson_fintech`。需求、讨论结论、设计、代码、测试和演示素材都属于版本管理范围，而不只是源代码。

Obsidian 继续作为个人知识库使用，也可以直接打开仓库中的 Markdown 文件；但不得复制并维护另一套项目需求或架构状态。

## 结果

优点：

- 代码和说明可以在同一个提交中原子更新；
- 协作者可通过 diff、评审和历史追踪决策；
- Agent 能通过需求 ID 定位完整影响范围；
- 自动检查可以阻止需求视图和台账不同步。

代价：

- 每次功能变更都要维护需求影响范围和测试；
- 团队成员需要遵守分支和 Pull Request 流程；
- Obsidian 中的想法只有落入仓库后才算项目决定。
