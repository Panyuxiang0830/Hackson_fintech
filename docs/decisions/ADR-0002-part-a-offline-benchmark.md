# ADR-0002：Part A 作为独立离线数据和检索模块

- 状态：Accepted
- 日期：2026-10-05
- 对应需求：REQ-014（team_decision），关联 REQ-003

## 背景

已运行的 Part A 导入公开或合成企业数据，构建 SQLite FTS5 与 RaBitQ IVF 索引。目标仓库已有 `src/` 安全问答和审计 MVP，需要让两部分可以独立运行，并准确记录其不同的权限执行位置。

## 决策

将 Part A 放入 `contextledger/`，提供单独依赖、CLI、Flask 演示、测试和数据重建说明。保留现有 Streamlit、身份服务、检索前权限过滤、回答和审计实现。

Part A 按 corpus 隔离文档和向量索引，候选召回后进行 ACL 校验。返回结果和直接打开均校验权限，但该设计不满足 REQ-002 的检索前过滤验收标准；本次不能据此提升 REQ-002、REQ-001 或 REQ-009 的完成状态。

正式问答整合仍需让 IdentityService 和确定性策略在检索前限定授权数据，并把回答、引用和审计接入现有服务。离线导出的成员及权限快照不能用于证明生产环境撤权即时生效。

公开或合成数据、原文件、缓存、索引及本机 native bindings 均保存在忽略的 `runtime/` 和 HF 缓存中。Git 只保存实现、依赖、来源说明和无正文的验证汇总。RaBitQ 绑定从固定上游 commit 构建，不提交本机二进制或研究分支修改。

## 结果

协作者可以复现 Part A 并审查来源 ACL、抽样及向量参数。原有安全 MVP 保持独立的可运行路径；离线检索的召回、实时同步和生产授权整合仍是后续工作。
