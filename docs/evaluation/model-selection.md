# REQ-009 模型选型记录

> 评测日期：2026-10-02
>
> 目的：为 ContextLedger MVP 选择一个默认回答模型，而不是建立永久模型排名。

## 候选模型

本次只比较当前 TokenHub 账号能够直接调用、且成本适合黑客松 MVP 的三个模型：

- `deepseek-v4.1-flash`
- `glm-5.3-flash`
- `hy4-preview`

官方模型列表显示三者支持结构化输出；价格以评测当天的[腾讯云模型价格](https://cloud.tencent.com/document/product/1823/130055)为准。`GLM-5.3-Flash` 的公开按量价格约为输入 1.07949 元/百万 Token、输出 3.5983 元/百万 Token；`DeepSeek-V4.1-Flash` 存在峰谷计费；`Hy4 preview` 约为输入 6 元、输出 18 元/百万 Token。

## 方法

所有模型使用相同的授权证据、温度 0、JSON 输出约束和低/关闭思考配置。样例包括：

1. 综合 Slack、Jira、Confluence 和 Google Drive，回答上线状态、根因和是否可以通知客户恢复，并解释证据关系；
2. 在证据没有财务损失数字时明确拒答且不返回引用。

检查项包括 JSON 可解析性、引用是否落在 `[1]` 至 `[4]`、关键事实、拒答行为、延迟和 Token 用量。该小样本只用于 MVP 选型，后续仍需使用 20–30 个固定问题做回归评测。

## 结果

| 模型 | 综合样例 | 证据不足样例 | 观察 |
|---|---|---|---|
| `glm-5.3-flash` | 通过，2.92 秒，正确引用四个来源 | 通过，2.01 秒 | JSON、时间关系和通知条件最稳定 |
| `deepseek-v4.1-flash` | 首次 JSON 解析失败；关闭思考后 2.06 秒返回，但把先后发生的通知条件误判为冲突 | 通过，1.79 秒 | 延迟较低，但本样例的时序综合不如 GLM 稳定 |
| `hy4-preview` | 90 秒超时 | 返回截断 JSON | 当前负载下不适合作为演示默认模型，且单价最高 |

TokenHub 是在线服务，单次延迟会随地域和负载变化；这里记录的是实际评测证据，不将一次结果解释为通用排名。

## 决定

MVP 默认使用 `glm-5.3-flash`，`reasoning_effort=low`。原因是：

- 对当前核心任务——跨来源、有条件、带引用的企业知识回答——一次通过；
- 能稳定返回 JSON，便于服务端校验引用；
- 成本适合频繁演示；
- 不需要为 MVP 维护多模型路由。

模型输出不是安全边界。服务端仍必须验证 `citation_ids` 与正文 `[n]` 标记完全一致且属于本次授权 Top-K；配置缺失、超时、解析失败或引用非法时退回确定性回答。
