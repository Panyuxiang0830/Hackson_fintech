# Submission Requirements：2026-10-15 核对记录

来源为用户提供的完整 43 页《AI CAN DO IT Tencent Cloud Hackathon Singapore 2026 Handbook》第 37 页，以及本次截图 [Submission Requirements](submission-requirements-20261015.png)。两者的字段与规则一致。核对日期不是官方版本发布日期；PDF 原件位于本地 hackathon 工作目录。

| 项目 | 表内规则 | 内容 |
|---|---|---|
| Project title | Required | AI Agent 项目名称 |
| Short blurb | Required | 概括项目功能或价值；严格少于 10 个英文单词 |
| Project Description | Required | Project Overview：目标场景、用户、价值；Real-World Scenario Insights：痛点来源、受众、核心问题；Comprehensive Solution Design：业务/技术架构和 Prompt 驱动生成；Business Value：量化指标或清晰定义的影响 |
| CodeBuddy / WorkBuddy Conversation History | Required | 至少 3 份开发过程中的真实聊天截图或屏幕录制 |
| Cover Image | Required | 16:9 封面；推荐尺寸 380×216px。推荐像素尺寸不是精确 16:9，当前封面采用 1920×1080 满足明确的比例要求 |
| Demo video | Optional | 如提交，长度 5–8 分钟；覆盖概览、核心功能/使用、开发方法与 CodeBuddy/WorkBuddy 使用反思 |
| Project link | Optional | 可访问的 live/demo URL；表内说明可加分 |
| Other Requirements as per the Challenge Statement | Optional | 检查相应赛题要求；不据此取消第 18–19 页五个场景的 worked example 要求 |

同页 Project Basic Requirements 另说明：项目必须原创且基于 CodeBuddy 或 WorkBuddy 至少一个产品构建；产品使用证明为必要条件，缺少证明不进入评分。此处没有确认团队已经满足该条件。报告正文、整理过的复现提示词和产品截图均不能代替表内要求的真实开发聊天材料。

FinTech 的用户与痛点以第 14–19 页为依据。Company A 的规模和约 30% 工作周用于搜索是赛题场景给定估计，不是项目实测收益。第 19 页混入医疗健康措辞，报告不以该段定义本案例用户或需求。
