## 更新规则

确认一项后：

1. 在本文件记录官方来源、确认日期和准确表述；
2. 更新 `project/requirements.json` 中 REQ-013；
3. 运行 `python3 scripts/project_sync.py`；
4. 若影响实现或交付，更新 `docs/product/roadmap.md`；
5. 通过 Pull Request 保留变更证据。
